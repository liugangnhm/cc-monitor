# Claude Code Monitor 紧凑 UI 设计方案

## 背景

当前 Claude Code Monitor 使用卡片网格布局，每个 session 一张卡片，最小宽度 300px。用户希望在小窗口中也能看到更多 session 状态，且窗口不应遮挡正在进行的工作。

## 目标

- 在很小的悬浮窗口中显示尽可能多的 session 状态
- 精简信息展示，只保留核心内容
- 支持在"紧凑列表"和"详细卡片"两种视图间切换
- 窗口半透明不遮挡工作，交互时变为不透明

## 设计

### 窗口特性

| 属性 | 值 |
|------|-----|
| 默认尺寸 | 300 × 400 |
| 最小尺寸 | 240 × 200 |
| 标题栏 | 无边框（自绘标题栏） |
| 拖动 | 按住标题栏区域可拖动窗口 |
| 置顶 | 保持 `WindowStaysOnTopHint` |
| 默认透明度 | 0.3 |
| 悬浮透明度 | 1.0 |
| 状态变化透明度 | 1.0（持续 3 秒后恢复 0.3） |

### 紧凑列表视图（默认模式）

每行一个 session，高度约 32px，一屏可显示 10-12 个 session。

布局：
```
┌─ Claude Code Monitor  [≡] [×] ─┐
│ 刷新 14:32 · 5 会话             │
├────────────────────────────────┤
│ ■ my-project   工作中  [3]     │
│ ■ backend-api  就绪    [1]     │
│ ■ docs-site    就绪    [0]     │
│ ■ old-session  已结束  [0]     │
│ ■ test-repo    工作中  [5]     │
└────────────────────────────────┘
```

每行内容：
- 左侧 4px 彩色竖条：黄=工作中，蓝=就绪，灰=已结束
- 中间：项目名称（从 `session.name` 或 `cwd` 的 basename 获取）
- 右侧：状态文字 + 任务数（如 `工作中 [3]`）

### 详细卡片视图

保持现有卡片网格布局，窗口自动放大到 1100×700。

切换时：
- 从紧凑 → 详细：窗口从当前位置放大到 1100×700
- 从详细 → 紧凑：窗口缩小到 300×400

### 视图切换

- 标题栏右侧放置两个图标按钮：`≡`（列表视图）、`⊞`（网格视图）
- 当前激活的视图按钮高亮显示
- 切换时保持窗口在屏幕内的位置

### 透明度控制

```
默认状态 ──→ 透明度 0.3
  │
  ├── 鼠标进入窗口 ──→ 透明度 1.0
  │   └── 鼠标离开窗口 ──→ 透明度 0.3
  │
  └── session 状态变化 ──→ 透明度 1.0
      └── 3 秒定时器到期 ──→ 透明度 0.3
```

### 数据刷新

- 保持 2 秒自动刷新
- 只在 session 数量 / 状态 / 任务数变化时才重绘 UI，避免闪烁
- 状态变化时触发透明度提示

## 实现要点

### 无边框 + 拖动

PySide6 中通过设置 `Qt.FramelessWindowHint` 隐藏标题栏，重写 `mousePressEvent` / `mouseMoveEvent` 实现拖动。

### 透明度

使用 `QWidget.setWindowOpacity()` 配合 `QTimer` 实现自动恢复。

### 紧凑列表布局

使用 `QVBoxLayout` 存放行 widget，每行是一个 `QWidget` 内部用 `QHBoxLayout`。

### 状态变化检测

在 `refresh()` 中比较当前 session 的签名（`session_sig`），签名变化时触发透明度提示。

## 未涵盖

- 自定义透明度值设置
- 自定义紧凑视图行高
